# 轮盘抽题 · 上海大学英语语言文学真题

一个单文件网页的扭蛋机：转动旋钮 → 扭蛋掉出来 → 弹跳几下 → 摇晃蓄力 → 啵地爆开，彩带飞溅中揭晓一道真题。带音效。手机上打开即用，可「添加到桌面」。

## 题库

**360 题 / 6 个扇区**，来自上海大学英语语言文学考研真题（2000–2026）与一份外国文学史复习笔记，只收录**名词解释**和**问答题**两类题型。

| 扇区 | 题量 | 主要来源 |
|---|---|---|
| 名解·语言学 | 71 | 620/623（2000–2013）、2012 语言学卷、622（2023–2026）、南师大 623（2019） |
| 名解·文学 | 194 | 618 英美文学史（2002–2015）、622（2023–2026）、上外文学（2013）＋《文学背诵》笔记（古希腊—中世纪—文艺复兴—17/18/19/20 世纪—亚非文学通史） |
| 名解·翻译 | 5 | 622（2023–2026） |
| 问答·语言学 | 31 | 620/623、2012、622、南师大 623 |
| 问答·文学 | 55 | 618 英美文学史、622、上外文学 |
| 问答·翻译 | 4 | 620（2000）、622（2023–2025） |

英文题目已译成中文，关键术语、人名、作品名保留英文原文。每题都标注了来源年份与科目。

同一道题跨年重复出现时已合并，年份并列（例如 `Black Humor → 2002／2005／2009 · 618 英美文学史`），可当作高频考点参考。

## 用法

直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址。

点顶部的一排按钮可以先圈定抽题范围（「全部」或某一类），然后转动旋钮：

1. 旋钮转一圈，玻璃球里的扭蛋跟着晃
2. 一颗扭蛋从出蛋口掉出来，落地弹几下
3. 扭蛋开始摇晃、发光蓄力
4. 啵——蛋壳炸成两半，闪光 + 彩带，题目揭晓

右上角 🔊 可以随时静音。音效是 Web Audio 现场合成的，没有外部音频文件，离线也能响。

**抽过的题会从池子里消失**，收进右下角的**潘多拉魔盒**：

- 抽过一道，池子就少一道，**再也不会抽到重复的**
- 右下角魔盒右上角的数字是魔盒里攒了多少题
- 点魔盒可以翻看**做过的每一道题**（题干、所属分类、来源、抽到的时间）
- 记录存在手机浏览器本地，关掉页面再打开还在
- 池子抽空了会提示，点魔盒里的「清空魔盒，把题放回池子」就能重新开始

池子的范围跟着顶部的「抽题范围」走：选「全部」时 360 题共用一个池子。

## 换题目

编辑 `index.html` 里的 `BANK` 数组（在 `/* ==== BANK_START ==== */` 与 `/* ==== BANK_END ==== */` 之间），无需改动其它代码：

```js
{ name: '分类名', questions: [
  '纯题干直接写成字符串',
  { q: '题干', src: '来源标注', options: ['选项A', '选项B'] }
]}
```

分类名会显示成顶部那排「抽题范围」按钮，建议 4–8 个、每个不超过 8 个字。
