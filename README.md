# 轮盘抽题 · 上海大学英语语言文学真题

一个单文件网页：转盘转出题目分类，停下后随机抽一道真题。手机上打开即用，可「添加到桌面」。

## 题库

**230 题 / 6 个扇区**，全部来自上海大学英语语言文学考研真题（2000–2026），只收录**名词解释**和**问答题**两类题型。

| 扇区 | 题量 | 主要来源 |
|---|---|---|
| 名解·语言学 | 71 | 620/623（2000–2013）、2012 语言学卷、622（2023–2026）、南师大 623（2019） |
| 名解·文学 | 64 | 618 英美文学史（2002–2015）、622（2023–2026）、上外文学（2013） |
| 名解·翻译 | 5 | 622（2023–2026） |
| 问答·语言学 | 31 | 620/623、2012、622、南师大 623 |
| 问答·文学 | 55 | 618 英美文学史、622、上外文学 |
| 问答·翻译 | 4 | 620（2000）、622（2023–2025） |

英文题目已译成中文，关键术语、人名、作品名保留英文原文。每题都标注了真题来源年份与科目。

同一道题跨年重复出现时已合并，年份并列（例如 `黑幕揭发运动 → 2011 · 英美文学`、`Black Humor → 2002／2005／2009`），可当作高频考点参考。

## 用法

直接用浏览器打开 `index.html`，或访问 GitHub Pages 地址。点转盘或按钮开始旋转，停下后自动显示抽中的题目。

同一分类内的题目抽完一整轮才会重复，不会连续抽到同一道。

## 换题目

编辑 `index.html` 里的 `BANK` 数组（在 `/* ==== BANK_START ==== */` 与 `/* ==== BANK_END ==== */` 之间），无需改动其它代码：

```js
{ name: '分类名', questions: [
  '纯题干直接写成字符串',
  { q: '题干', src: '来源标注', options: ['选项A', '选项B'] }
]}
```

分类名就是转盘扇区上的文字，建议 4–8 个、每个不超过 8 个字（过长会自动截断）。
